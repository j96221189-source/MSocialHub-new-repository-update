# MSocialHub Brand

- Brand: MSocialHub
- Tagline: Your social services. One hub.
- Domain currently planned: msocialhub.example (placeholder)
- Visual style: charcoal, white, forest green
- Positioning: social media content and management services with customer order tracking.

Domain note: the earlier plan, msft-auth.co, was dropped. "MSFT" + "auth" reads like a Microsoft sign-in page, so browsers and email filters are likely to flag it as phishing and it invites trademark complaints. Register a domain built on the brand itself (for example a msocialhub name) before launch.

Brand note: MSFT is associated with Microsoft. Avoid Microsoft logos, visual trade dress, or wording that implies affiliation. Check domain appropriateness and trademark conflicts before public launch.

Supplier safety: mock mode only; no live SocialPlatforms API calls or purchases are enabled.
